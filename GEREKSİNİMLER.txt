====================================================
  Servis Hakediş ve İcmal Otomasyon — Gereksinimler
====================================================

Bu belge, projeyi farklı bir bilgisayarda derlemek ve çalıştırmak için
gereken tüm yazılım ve bağımlılıkları açıklar.


------------------------------------------------------
1. ZORUNLU YAZILIMLAR
------------------------------------------------------

a) .NET 8 SDK (Derleme için)
   İndirme: https://dotnet.microsoft.com/download/dotnet/8.0
   Sürüm   : 8.0 veya üzeri
   Not     : "SDK" indirin, sadece "Runtime" yetmez.

b) Microsoft WebView2 Runtime (Çalıştırma için)
   İndirme: https://developer.microsoft.com/tr-tr/microsoft-edge/webview2/
   Not     : Zaten yüklü olabilir (Windows 11 ile birlikte gelir).
             Uygulama açılmıyorsa bu paketi kurun.

c) Python 3.10 veya üzeri (İcmal Kontrol.py için — isteğe bağlı)
   İndirme: https://www.python.org/downloads/
   Not     : Sadece "İcmal Kontrol.py" scriptini kullanmak isteyenler içindir.
             Python kurulurken "Add Python to PATH" seçeneğini işaretleyin.

------------------------------------------------------
3. KURULUM VE ÇALIŞTIRMA ADIMLARI
------------------------------------------------------

Adım 1 — Depoyu klonlayın:
  git clone https://github.com/bugraturkoglu17-spec/Projeler.git
  cd Projeler

Adım 2 — Projeyi derleyin:
  cd HakedisOtomasyon
  dotnet build

Adım 3 — Uygulamayı çalıştırın:
  dotnet run --project src/HakedisOtomasyon.Web

  veya Windows'ta yayın (publish) oluşturup .exe olarak kullanın:
  dotnet publish src/HakedisOtomasyon.Web -c Release -r win-x64 --self-contained false -o ./ServisHakedis
  ServisHakedis\HakedisOtomasyon.Web.exe


------------------------------------------------------
4. İCMAL KONTROL SCRİPTİ (İcmal Kontrol.py)
------------------------------------------------------

Bu script uygulamayı başlatmak için yardımcı bir araçtır.
Çalıştırmak için:

  python "İcmal Kontrol.py"

  veya çift tıklayın (Python PATH'e eklenmiş olmalı).

Script otomatik olarak şu kontrolleri yapar:
  - WebView2 Runtime kurulu mu?
  - HakedisOtomasyon.Web.exe dosyası mevcut mu?


------------------------------------------------------
5. VERİTABANI
------------------------------------------------------

Uygulama SQLite kullanır. Veritabanı dosyası (hakedis.db)
ilk çalıştırmada otomatik olarak oluşturulur.
Mevcut verilerinizi taşımak istiyorsanız:
  ServisHakedis/hakedis.db  dosyasını yeni bilgisayara kopyalayın.


------------------------------------------------------
6. İŞLETİM SİSTEMİ
------------------------------------------------------

  - Yalnızca Windows 10 veya Windows 11 (64-bit) desteklenir.
  - WPF + WebView2 kullandığı için macOS/Linux'ta çalışmaz.
